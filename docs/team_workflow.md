## Work ready for members to claim

| --- | --- | --- |

Members should claim tasks with their own GitHub accounts. Assign named owners
only after they agree; roles in this table are proposed responsibilities.
Reviewers should check provenance, unsupported claims, tests and reproducibility,
and leave substantive review feedback where needed. Review status stays pending
until an actual review exists.

Do not backdate activity, create artificial commits, impersonate authors or close
research/user-feedback tasks merely because a protocol was added. Code evidence,
stakeholder feedback and teammate review are separate deliverables.

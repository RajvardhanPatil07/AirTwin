# Vengeance UI components

`spotlight-navbar.tsx` and `animated-button.tsx` are adaptations of the MIT-licensed Vengeance UI components by Ashutoshx7. See `VENGEANCE-LICENSE`.

Sources:
- https://www.vengeanceui.com/components/spotlight-navbar
- https://www.vengeanceui.com/components/my-animated-button

Adaptations: controlled step navigation, native button semantics, Vite-compatible styles, AirTwin palette, static readable button content, and reduced-motion support.
